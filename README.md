# Federal Reserve (federal-reserve)

The FRED API is a web service that allows developers to write programs and build applications that retrieve economic data from the FRED and ALFRED websites hosted by the Economic Research Division of the Federal Reserve Bank of St. Louis.

## APIs

### Federal Reserve FRED API

The FRED API allows developers to retrieve economic data from the Federal Reserve Bank of St. Louis including categories, releases, series, sources, tags, and observations across thousands of economic time series.

- **Human URL:** [https://fred.stlouisfed.org/docs/api/fred](https://fred.stlouisfed.org/docs/api/fred)
- **Base URL:** `https://api.stlouisfed.org/fred`
